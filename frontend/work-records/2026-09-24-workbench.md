# 前端工作台：设计规范与页面框架

工作日期：2026-09-24。根据两份 HTML demo 生成前端设计规范并搭建页面框架。

## 本阶段目标

- **做什么**：把主导航展开态和收起态整合为同一个 React 工作台，整理可执行的设计规范。
- **为什么**：先固定布局、组件边界与本地交互，为真实会话、流式运行和审批接入提供展示基础。
- **用什么 API**：React 状态管理、CSS Grid/Flex、localStorage、Clipboard、Blob 下载、原生 dialog；Tauri 提供桌面宿主。本阶段没有调用后端 HTTP/SSE。

视觉依据：[展开 demo](../../design/demo.html)、[收起 demo](../../design/front-end-demo.html)。功能边界依据：[前端 PRD](../../docs/frontend-prd.md)。实施规范见 [frontend/design.md](../design.md)，运行方式见 [frontend/README.md](../README.md)。

## 已完成

- 新增前端 design.md，定义布局、视觉 token、字体、组件、响应式、可访问性与后续 API 边界。
- 实现 40px 应用栏、256px / 64px 主导航、256px 会话历史、居中消息区与输入区。
- 主导航展开和收起共用入口数据；折叠偏好保存到 localStorage。
- 历史支持本地标题过滤、分组、会话切换、新建空会话与无匹配提示。
- 草稿按会话隔离；空会话建议任务可填入输入框。
- 消息支持用户与 Agent 样式、代码行号与复制、可折叠工具结果。
- 提供命令面板、运行详情空态、Markdown 导出以及 Cmd/Ctrl 快捷键。
- 实现窄屏覆盖侧栏、手机单栏与底部详情面板；消息与历史独立滚动，输入区占据布局空间。
- 使用仓库现有 logo、Phosphor 图标和本地打包的 Geist / JetBrains Mono 字体。
- Tauri 初始窗口调整为 1440×900，最小 390×600；保留平台原生窗口装饰。
