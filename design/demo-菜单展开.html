• 分析需求：Tauri v2 event 与 channel 机制支持异步数据流，原生 IPC 每次 invoke 会产生闭包，高吞吐量下需通过 Channel 结构进行背压控制与取消信号传递。

• 关键设计：引入 Web 标准的 AbortController 作为生命周期核心，定义事件状态机：Init → Streaming → Complete | Aborted。

• 安全约束：结合 Zod 或 TypeScript 谓词函数进行帧解码与内存回收防抖，阻断内存泄漏。

针对前端侧边栏会话切换造成的竞态问题，可以通过在路由钩子或 Session Store 中绑定全局上下文广播：

1. 在 useSessionManager 切换逻辑中持有活跃 activeControllerMap.get(sessionId)?.abort()
2. 发送 Rust 端指令 invoke("abort_ipc_channel", { sessionId }) 回收 Tauri 底层 Tokio 任务句柄

这样即可确保旧通道的事件流立即终止，避免跨会话的数据污染与内存积压
