## 命令与证据

仓库根目录：

```powershell
uv lock --offline --check --cache-dir .scratch/uv-cache
cargo metadata --offline --locked --no-deps --format-version 1 --manifest-path frontend/src-tauri/Cargo.toml
.venv/Scripts/ty.exe check packages/harness/shikigen app
.venv/Scripts/ruff.exe check app/server.py
.venv/Scripts/ruff.exe format --check app/server.py
```

服务专项使用 unittest discovery，并附加 verbose 与定时堆栈取证：

```powershell
.venv/Scripts/python.exe -u -c "import faulthandler,sys,unittest; faulthandler.dump_traceback_later(45, repeat=True); suite=unittest.defaultTestLoader.discover('tests', pattern='test_server.py'); result=unittest.TextTestRunner(verbosity=2).run(suite); faulthandler.cancel_dump_traceback_later(); sys.exit(0 if result.wasSuccessful() else 1)"
```

`frontend` 目录：

```powershell
node --import tsx --test --test-concurrency=1 tests/*.mjs
node --import tsx --test --test-concurrency=1 '--test-name-pattern=^real Vite skips an occupied port, holds the new listener through Tauri, and releases it on exit$' tests/tauri-command.test.mjs
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vite/bin/vite.js build
```

版本断言脚本、原始日志、命令开始／结束时间和退出码保存在本机 `.scratch/release-0.2.0/`。两个子 agent 的完整报告为 `backend-metadata-verification.md` 和 `frontend-verification.md`；主要结果日志为 `metadata-check.log`、`test-server-privileged.log`、`frontend-tests.log`、`tauri-command-targeted.log`、`typescript-check.status.txt`、`vite-build-final.log` 及对应状态文件。

## 首次异常与处理边界

- 默认沙箱中的服务测试阻塞在 Windows 事件循环的本机 socketpair 初始化。保留静默运行及诊断堆栈，授权环境中的最小事件循环探针通过后，仅复核原服务专项，17 项通过。
- OpenAPI 初次探针将字典当作对象访问，修正探针为 `openapi()['info']['version']` 后确认 0.2.0；产品代码未因此修改。
- `pnpm build` 在锁文件供应链策略预检停滞约 222 秒，项目构建脚本尚未开始，随后中断。使用 package 脚本中同样的本地 TypeScript、Vite 两步完成检查，未重装或升级依赖。
- 第一次直接 Vite 构建只记录到模块转换，子 agent 回合因额度耗尽中断，原会话失效且没有退出码。确认原进程不存在后，只重新执行 Vite 构建一次，取得最终成功结果；已通过的测试和 TypeScript 检查未重复。
- 研究文档的两处 Markdown 尾随空格改为反斜线硬换行，保持原显示语义；最终暂存检查由主 agent 执行。

本次未重跑后端全量、Rust 编译、原生窗口和安装包验收。后端业务自工具验证基线没有变化，本次只更新 API 版本字符串；历史全量结果及边界见[工具库验证索引](../wayfinder/tools-workflow/validation.md)。统一扩展页的原生视觉覆盖仍待后续实机验收，Windows 安装包与 Python 随包分发不属于本次交付。
