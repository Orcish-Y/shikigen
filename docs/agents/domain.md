# Domain Docs

工程技能探索项目时使用的领域文档布局。

## 本仓库布局

本仓库按单上下文维护领域文档：

- 根目录 `CONTEXT.md`：项目统一的领域词汇与业务规则
- `docs/adr/`：项目级架构决策记录

## 探索前读取

- 阅读根目录 `CONTEXT.md`（若存在）
- 阅读 `docs/adr/` 中与当前工作相关的决策（若存在）
- 如果未来新增根目录 `CONTEXT-MAP.md`，按索引读取相关上下文及对应决策

## 使用领域词汇

在 issue 标题、重构建议、假设或测试名称中使用 `CONTEXT.md` 定义的术语。如果需要的概念尚未定义，先确认它是项目真实概念还是临时造词；必要时再补充领域模型。

## 标出 ADR 冲突

如果建议与现有 ADR 冲突，明确指出对应 ADR 和冲突点，不要静默覆盖。
