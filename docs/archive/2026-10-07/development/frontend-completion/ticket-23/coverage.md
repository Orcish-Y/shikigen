### 什么证据可以说明什么

| 证据层 | 能证明 | 不能据此声称 |
| --- | --- | --- |
| HTTP／Runtime／前端纯逻辑测试 | 公开请求／响应、投影、持久事务、回滚、错误分类、受控乱序／迟到／时钟及边界规则；优先以公开事实和请求记录断言 | 真实 WebView 呈现、Windows 操作系统行为、真实模型供应商执行 |
| 受控 Tauri 离线 fixture | 真实 Windows Tauri/WebView2 窗口、隔离后端／SQLite、公开 HTTP、可控 Agent 与页面操作；现有票的 result JSON、请求、消息／事件事实和 WebView 截图属于此层 | fixture 本身不能证明未记录的 OS 输入、IME 候选 UI、OSK 按键或下载退出后持久性；需引用对应的直接 OS 结果。真实外部模型另按 provider 记录；不预设下载一定显示特定 SaveAs 窗口 |
| 真实模型任务 | 配置的外部模型在实际桌面工作流中的回答、工具调用和持久结果 | 不能由固定 Agent、录制响应、Mock 或离线 Harness 冒充 |
| 真实 Win32／系统交互 | `SendInput`／`InjectTouchInput` 经 Windows 送达的键盘／触摸事件、实际 OSK 窗口、系统 IME 组合、OS 标题栏／边框及默认程序的直接观察；每项只证明原始结果记录的具体交互 | CDP 合成的 `isTrusted` 事件、`imeSetComposition`、DOM `KeyboardEvent`、WebView 截图或仅有 native rect/DPI 数字，不能代替 OS 事件证据。OS 注入不是实体手指／人工键盘观察，但 PRD／AC6 不把人工操作列为前置 |
