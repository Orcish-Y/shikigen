# 工具测试取消、超时与编辑生命周期

12 号票实现记录。依据[执行决议](tickets/003-execution-test-contract.resolution.md)、[编辑生命周期决议](tickets/004-management-ui-lifecycle.resolution.md)和[工具页面原型](../../../frontend/design.md#工具页面原型)。

## 公开测试 API

已保存工具使用 `POST /api/tools/{tool_id}/tests`，有效草稿使用 `POST /api/tools/tests`。两者返回 202 和当前后端进程持有的临时测试身份；草稿不落盘，手动测试允许禁用工具，普通调用继续检查启用资格。

开始接口在同一个请求中校验工具定义、创建记录并启动任务，由后端生成 UUID，在 202 响应的 `data.test_id` 中返回。不再提供独立登记接口，开始请求也不接受客户端传入 `test_id`。每次明确发起的新测试都会创建新身份，不自动重发业务操作。

`GET /api/tools/tests/{test_id}` 查询状态。`POST /api/tools/tests/{test_id}/cancel` 等本次执行和清理结束后返回真实观察；重复取消返回同一终态，已经完成的成功或失败不会被改成取消，未知身份返回 404。查询不启动连接，不调用业务工具。进程内最多保留 100 项观察，容量不足时先淘汰已完成且任务引用已清空的记录，不建立持久测试历史。

取消只接收 `test_id`，由后端记录取得任务并请求取消；未知 ID 不创建占位。取消和查询统一 UUID 格式。不再维护登记状态、登记截止时间、过期扫描或待交接取消集合。

观察包含 `test_id`、`tool_id`、`created_at`、`status`、`result`，另含 `cancel_requested` 和启动时的脱敏 `inputs`。快照只用 `status` 表示状态：`running` 为执行中，`success`、`error`、`timeout`、`cancelled` 为四种终态；没有 `reserved` 或 `phase`。执行中保持页面编辑锁定并支持查询／取消，进入终态后恢复编辑。请求被接收后交给应用生命周期持有，HTTP 等待者断开不代表取消执行；取消是单独的明确动作。取消请求断开也不打断已经开始的资源清理。生命周期关闭先停止接收并交接创建操作，再取消和收回当前测试任务。

测试任务尚未获得首次调度也可取消。重复取消和关闭不会在已有取消或超时的清理期间再次注入取消。

后端只维护 `_test_records`，每个 `ToolTestRecord` 集中保存对外快照和可选的执行任务。完成回调清空任务引用并保留终态快照；取消和关闭直接从记录取得任务。执行任务属于进程内部数据，对外仅返回 `snapshot`。

## 预算、返回和清理

工具总预算默认 30 秒、范围 1–300 秒，从统一执行入口准备本次定义开始，涵盖子进程启动、MCP 初始化和来源读取、业务调用、完整结果读取。取得定义后按同一起点设置其截止时间。MCP 连接检测和发现继续独立使用连接上的各自预算。

终态为 `success`、`error`、`timeout`、`cancelled`，保留 `data`、`error`、`duration_ms` 和类型详情。新增只读 `data_available`：显式返回的 `null` 为 true，没有取得业务返回值为 false；后者的默认 `data: null` 不代表真实响应。HTTP 已收到的状态和响应头在读取超时／取消时仍保留。Python 调试输出和退出码在清理后回填，完整详情仍可展开、查看和复制。

Python 取消／超时终止并等待本次子进程，移除执行临时目录。HTTP 的流式响应和客户端退出上下文；MCP 释放本次会话、stdio 进程或 HTTP 客户端，并按现有传输规则尝试终止远端会话。清理发生在返回终态前，可能使 `duration_ms` 超过预算。不承诺停止所有派生进程或撤销远端已发生的业务操作，不自动重试业务请求。

原有限额继续有效：实际返回上限 1 MiB，超出返回明确失败；Python stdout/stderr 合计保留最后 64 KiB，标记截断。取消／超时不会拿部分响应伪造成功数据。

## 可展示结果的脱敏

执行结果和测试观察输入遮盖本次已知认证字符串，包括 HTTP 认证绑定、敏感名称的固定头／URL 查询参数、MCP 认证头和敏感名称的环境变量；Bearer 值同时识别含前缀和去前缀的形式。JSON 中的字符串、对象键及常见 URL／JSON 转义回显统一遮盖，覆盖 data、error、details 和输入观察。保留其它 JSON 值及类型。

这只处理执行观察。认证配置继续按用户确认直接编辑、保存和回填真实值，见[认证记录](http-auth-credentials.md)，未引入 credential 管理或保留／替换／清空协议。无法识别未知秘密或任意变换后的秘密。

## 页面交互

同一编辑页只运行一次测试，开始时保留有效草稿和输入，运行期间锁定编辑、启用、保存、删除及重复执行；显示启动、执行或取消清理状态，提供明确取消入口。完成后恢复编辑；修改配置标记旧结果。

已取得测试 ID 时，页面切换、选择其它工具或关闭编辑先显示“取消测试并离开／继续测试”。前者等清理后再检查未保存草稿，继续提供保存并离开、放弃修改、继续编辑；取消测试本身不丢弃草稿。取消请求失败保留现场并提供查询／重试，查询响应不会覆盖更新的取消结果，旧宿主的迟到响应不会覆盖新宿主页面。

尚未取得开始响应时，页面显示等待启动响应并锁定编辑，不能声称工具尚未执行，也无法发送有效查询或取消。开始响应丢失时明确提示结果不确定，保持锁定，不自动重试；此时后端执行仍由执行预算和生命周期清理约束。用户可明确选择“停止等待”或“停止等待并离开”，结束前端等待并恢复操作；停止等待不代表后端已取消，离开仍检查未保存草稿，迟到开始响应不能恢复已放弃的观察。明确的 404／409／422 拒绝则提示无法开始并解除锁定，允许修正后重新测试。

AI Elements Tool 按真实状态展示四种终态。真实 null、false、0、空字符串保留 JSON 表示，没有返回数据显示“未取得返回数据”。前端使用后端已脱敏输入观察，完整结果查看与复制沿用相同的脱敏数据。

布局沿用原型的 64px 主导航、256px 工具侧栏、48px 操作栏和 7:5 双栏；窄屏堆叠，取消与草稿确认操作可达。
