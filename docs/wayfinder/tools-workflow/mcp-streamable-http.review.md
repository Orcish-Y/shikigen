## Spec

审查与全量验证发现以下问题，均已修复并通过复查：

- 终止请求仅设置 HTTPX 空闲超时，持续慢速返回仍可能拖住取消。改为 DELETE 的 0.5 秒总截止，本地慢滴服务验证超时及后端关闭能有界完成。
- SSE 提前结束而没有结果时，默认 SDK 会一直等到预算耗尽。无可恢复令牌时，明确返回传输错误；非法 JSON-RPC 和 HTML 响应通过公开 message_handler 返回协议异常。
- 提前结束的处理不能拦截 SDK 已支持的续读。通过公开令牌回调区分可恢复响应，带事件 ID 时保留 Last-Event-ID 续读；公开 API 验证发现成功，业务工具没有执行。
- 取消后的迟到响应不能改写取消状态。stdio 保持 SDK 默认 handler；HTTP 错误回调只处理仍进行且未被取消的操作，结束后忽略迟到消息。修复后远程与 stdio 共 19 项 API 回归通过。
