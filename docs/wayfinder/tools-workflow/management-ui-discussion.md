# 工具管理页面与增删改生效规则：讨论记录

状态：已完成，2026-10-13。所属票据为[确定工具管理页面与增删改生效规则](tickets/004-management-ui-lifecycle.md)。两轮规则已由用户确认；本文件保留提问和反馈，最终规范见[页面与生命周期决议](tickets/004-management-ui-lifecycle.resolution.md)。规划完成不表示应用代码已实现。

## 第一轮：当前可决定的问题

| 问题 | 推荐方案 |
| --- | --- |
| Q1 页面组织 | 主导航工具入口；工具库/MCP 连接两个页签；列表搜索、类型和启用筛选；完整编辑页；HTTP 手工创建与 OpenAPI 导入入口。 |
| Q2 未保存编辑 | 显式保存，测试不保存；离开时保存并离开/放弃/继续编辑；失败保留草稿；首版只在页面内存保留，不跨重启，不将密钥存入浏览器本地存储。 |
| Q3 启用与测试 | 新建默认启用；禁用阻止消费者调用，但允许显式手动测试；启用状态、最近测试结果/时间及配置诊断分别显示，不自动探测，不宣称持续在线。 |
| Q4 MCP 连接保存 | 配置合法即可保存，连接失败不阻止；测试连接/发现分别操作，不调用业务工具；发现失败保留已有结构。 |
| Q5 MCP 重新发现 | 预览新增/结构变化/本次未发现；勾选添加或应用更新；相同来源保留 ID、本地名称/说明/启用/超时；不自动删除或禁用未返回项，实际调用以执行结果为准。 |
| Q6 删除 | 工具直接删除、无回收站，提示未来 ID 引用失效；删除连接列出旗下工具并确认一起删除；首版不查询消费者引用表。 |
| Q7 修改生效 | 每次调用开始时取得最新定义、连接、凭据及完整源码；本次使用取得的内容，后续修改影响下一次；已构建封装也在新调用时重新检查。 |
| Q8 Schema 无损编辑 | 表格仅编辑能准确表达的字段；复杂部分摘要/高级编辑；保留其他约束、说明、示例，不重建覆盖；不能无损表达时不在表格改类型；MCP 来源只读，HTTP 分组和映射保持一致。 |
| Q9 Python 参数同步 | 源码修改自动静态解析，保存/测试再核对；名称、数量、必填性以 main 为准；同名且类型兼容保留补充信息；新增待补、删除/改名/不兼容明确展示，不猜迁移；表格不直接改源码参数名。 |
| Q10 输出与测试区 | Python/HTTP 可选输出 Schema 高级编辑，MCP 只读；JSON 对象录入测试输入，显示参数说明；状态/耗时/data/错误/详情完整查看复制；页面保留最近一次结果，不建历史，不自动反写 Schema。 |
| Q11 保存一致性 | 代码先写新生成文件、再替换 config.json 引用、最后清理旧文件；ID 稳定，无历史版本功能；MCP 入库/OpenAPI 所选批次全部校验后一次保存，保留其他配置分组。 |
| Q12 外部修改 | 打开/刷新/保存/调用时检查文件变化，无后台监视；有草稿则提示冲突且保留，不静默覆盖磁盘；坏配置、缺失文件或源码/schema 不一致明确诊断，不执行旧内容；只热更新工具库。 |
| Q13 Git 忽略 | 自动生成的 config/tools/ 作为本地配置排除；可分享示例另放可提交目录。 |

## 第一轮用户答复

用户回复：“Q1 主导航中添加一项‘扩展’（你看一下有没有更精准的用词），扩展下分为工具（你看一下工具和mcp是不是需要分成两个），skill等。Q9 如果是可执行代码。只可以预览表单中的属性，没有明确的类型可以用下拉菜单选择。其他同意推荐。”

- Q2–Q8、Q10–Q13 按第一轮推荐确认，不再重复征求。
- Q1 改为主导航总入口容纳工具、MCP 与 Skill；具体分层与首版范围随后通过 Q14 确认。
- Q9 的 Python 参数表改为预览为主：源码已能确定的属性只读，未能确定的类型用下拉补齐；高级补充及重新解析保留规则随后通过 Q15 确认。

## 第二轮：修订和后续边界

状态：用户对 Q14–Q18 回复“同意推荐”，全部接受。下面保留当时推荐，最终行为以决议为准。

| 问题 | 推荐方案 |
| --- | --- |
| Q14 扩展导航 | 将现有工具与技能编排入口调整为扩展，下设工具/MCP 服务/技能；工具统一包含 MCP、Python、HTTP，MCP 服务管理连接和发现并可跳转查看旗下工具；技能首版暂未开放，不增加 Skill 管理实现。 |
| Q15 Python 预览与补充 | 源码确定的名称、类型、必填性、默认值只读，未知类型用下拉补齐；高级 Schema 补说明/约束/null/容器结构及 **kwargs 业务字段，不能改源码确定的属性；同名仍未知保留选择，明确新注解以源码为准且提示冲突；不修改源码或自动构造自定义类。 |
| Q16 测试运行中 | 单编辑页一次一个测试，运行中锁定编辑/保存，可取消；离开提供取消并离开/继续；结束恢复编辑，随后修改将旧结果标为修改前的结果；无后台测试列表或重启恢复。 |
| Q17 保存提交与清理 | config.json 更新成功为生效点；之前失败保留原定义，之后清理失败仍保存/删除成功并提示残留；请求结果不明时重新读取核实，不自动重试创建或断言未保存。 |
| Q18 类型和来源 | 工具类型固定；MCP 工具所属连接/远端名只读，换连接重新发现新建；连接配置可编辑保留 ID，提示重新发现但不覆盖已保存结构；HTTP 编辑规则沿用已确认决议。 |
