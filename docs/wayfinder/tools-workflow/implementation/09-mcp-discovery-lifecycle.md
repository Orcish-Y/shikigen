**What to build:** 用户重新发现 MCP 服务，明确选择添加或更新工具，保留同来源身份与本地编辑；可以修改连接并在确认影响后删除连接及旗下工具。远端暂时不可用或本次未返回某工具不会自动破坏工具库。

**Blocked by:** 03：工具编辑、启用、删除与草稿测试；07：接入 stdio MCP 并调用选中工具。

**Status:** done

- [x] 重新发现先预览新增、来源结构变化和本次未发现项，再由用户勾选添加或应用更新；没有选择的变更不写入，操作本身不执行业务工具。
- [x] 同一 server_id 加 remote_name 更新保留工具 ID，一项来源只有一项入库工具；选中来源输入/输出变化应用后，本地页面名称、调用名称、说明、启用和超时保留。
- [x] 本次未发现项保留并显示本次未发现，不自动删除或禁用；发现失败保留已保存结构，不用空结果覆盖。实际调用按当次结果判断，远端改名不猜测为旧工具改名。
- [x] 应用选择之前核对连接/工具库读取版本和名称/来源冲突，整批验证后一次提交，冲突或无效项有具体诊断，不半保存；完整磁盘变化处理由 13 统一加强。
- [x] 普通编辑权限检查与发现应用分开：合法发现更新通过独立后端入口核对来源和版本，再复用定义校验及配置提交，不能被普通编辑的来源字段只读检查拦截；公开 API 同时验证普通编辑/草稿测试拒绝来源 schema 变更、发现更新允许并保留 ID/本地信息。
- [x] MCP 工具所属连接、远端身份和来源 schema 在普通编辑中只读，服务端也拒绝改写；换连接重新发现创建新工具，改本地名称不改变远端调用身份。
- [x] 编辑连接命令、地址或凭据保留连接 ID，显式保存后提示重新发现核对结构，不自动覆盖已入库 schema；连接脏草稿离开和保存失败遵循公共草稿规则。
- [x] 删除连接前显示旗下工具及数量并确认，单次配置提交一起移除连接和其工具，未来引用明确失败，不留无连接定义；删除不撤销已经开始的调用。
- [x] 服务页可跳转查看所属已入库工具；读取/保存错误、暂离线和来源变更有真实反馈，所有可显示信息遵循凭据隐藏。
