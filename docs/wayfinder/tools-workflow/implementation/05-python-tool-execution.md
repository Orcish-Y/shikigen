# 05: 创建并测试带注解的 Python 工具

> 历史开发票：2026-10-23 从本机 scratch 迁入，保留原状态、验收项和阶段记录。当前实现与后续修订先读[开发指南](../README.md)和[实施索引](index.md)。

**页面原型：** 涉及工具页的开发与验收，先读取并遵循[工具页面原型与参照规则](../../../../frontend/design.md#工具页面原型)。

**What to build:** 用户在工具页编写带常见标量注解的 main，系统静态解析并预览参数，保存源码后通过动态表单真实执行，分别查看业务返回与调试输出。使用后端同一解释器的本机子进程，不要求用户把具名参数包成 args。

**Blocked by:** 02：HTTP 参数映射与动态表单。

**Status:** completed

- [x] 工具库增加 Python 专属定义和登记适配器，公共字段与稳定身份沿用已有契约；唯一入口为顶层同步 main，可包含辅助函数，不提供 entry_function 配置。
- [x] 对普通具名参数及函数默认值静态解析 str/int/float/bool 等标量注解，生成 input_schema 和只读参数预览；名称、已知类型、必填性、默认值不能在表单任意重写。更复杂签名和未知类型由 06 完成，本票先明确诊断而不猜成任意 JSON。
- [x] AST 解析、录入、保存不执行或 import 用户代码，不 eval 注解和默认表达式；缺少/重复 main、语法错误及不支持入口明确诊断，不执行未核实的旧结构。默认值展示与允许省略分开于 nullable。
- [x] 持久定义只保存相对 code_path，源码写入配置旁的受管理生成目录；路径相对实际配置目录解析，改变进程 cwd 不改变目标。缺失、不可读或非法路径明确失败，不执行空代码。生成代码目录按本地配置加入 Git 忽略，可分享示例单独保存。
- [x] 完整新源码先写新生成文件并关闭，再提交引用它的新配置；旧引用保留到配置提交完成，清理仅针对目录内受管理且未引用生成文件。不存在内联源码或把源码草稿作为持久配置的第二份副本。
- [x] rjsf 使用解析后有效 input_schema 渲染实际参数，源属性只读不妨碍填写参数值。后端先严格校验输入，在已授权执行子进程核对实际入口与签名绑定，按参数名调用；函数默认值正常生效，schema 默认值不自动注入。
- [x] 每次调用启动独立子进程，使用后端解释器、标准库和已安装依赖，独立临时工作目录结束后清理；不自动安装依赖或创建工具环境，本机权限执行不称为安全沙箱。
- [x] main 返回严格 JSON 值，结构和类型保留；NaN/Infinity、不可序列化返回、运行异常分别明确失败。stdout/stderr 与返回协议分离，记录退出信息，调试输出保留最后 64 KiB 并标记截断，实际结果仍受 1 MiB 上限约束。
- [x] 执行使用取得的完整源码副本并遵守统一预算和结果契约；后续 12 补完整取消控制，13 核对外部修改及读取/清理协调的异常场景。
- [x] 通过公开 API、临时配置和真实 Python 子进程验证静态解析无业务副作用、具名输入、函数默认值、绑定错误、源码重读和严格返回；页面验收源码编辑、参数预览、动态输入及完整结果，并完成相关后端、前端测试与构建。
