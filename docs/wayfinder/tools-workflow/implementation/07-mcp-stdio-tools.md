# 07: 接入 stdio MCP 并调用选中工具

> 历史开发票：2026-10-23 从本机 scratch 迁入，保留原状态、验收项和阶段记录。当前实现与后续修订先读[开发指南](../README.md)和[实施索引](index.md)。

**页面原型：** 涉及工具页的开发与验收，先读取并遵循[工具页面原型与参照规则](../../../../frontend/design.md#工具页面原型)。

**What to build:** 用户在 MCP 服务页保存一个本地 stdio 连接，分别测试连接和发现工具，勾选需要的工具入库，再在统一工具页面填写参数并真实调用。服务连接、远端工具来源和本地工具信息分别表达。

**Blocked by:** 04：HTTP 认证；涉及连接凭据管理前需统一设计。

**Status:** 部分完成（stdio 主链路已实现；敏感字段与遮盖待统一凭据设计）

**04 当前范围（2026-10-15 用户调整）：** HTTP 认证保留，密钥直接使用 `auth[].value`；通用 `Credential`、已设置标志、留空保留／显式清空协议、日志与结果遮盖已移除，后面统一设计。接入 MCP 敏感字段前需完成统一凭据设计，不能假设上述模块仍可复用。下文相关验收项是后续目标，当前状态见[HTTP 认证记录](../http-auth-credentials.md)。

- [x] 可通过动态管理表单及公开 API 保存/读取 stdio 连接，拥有稳定连接 ID，包含 command、args、env、cwd 等专属配置和独立测试/发现预算；格式合法时服务暂时不可达仍可保存。
- [ ] 连接保存到工具库独立连接集合，同一连接供多个工具引用；不覆盖原有启动自动 MCP 配置，不自动挂载当前聊天 Agent。连接敏感字段使用已设置/保留/替换/清空与遮盖机制。
- [x] 测试连接、发现和业务调用分别操作，测试连接/发现不执行业务工具；页面可查看真实状态和诊断，连接/发现默认 30 秒并可调整，不从启用推断在线。
- [x] 发现结果预览后仅将勾选工具入库，MCP 定义包含 server_id、remote_name 和完整来源 schema；同一来源重复入库识别为原项并保留 ID，不创建第二份。详细来源更新与未发现处理由 09 完成。
- [x] 本地调用名称自动区分来源重名并避开内置名称，冲突明确反馈；整批所选项校验后一次保存，任一无效不能提交一半，未勾选来源不进入工具库。
- [x] 来源输入/输出 schema、所属连接和远端身份只读，公共本地名称/说明/启用/超时遵循管理权限；rjsf 可根据有效来源 input_schema 填写实际参数，原 arguments 不额外包装，复杂值可用高级 JSON。
- [x] 每次发现/调用独立初始化会话并结束关闭，stdio 进程内状态不保证跨调用；会话获取/释放经提供者边界，为常驻/跨会话升级保留位置，首版不实现会话池。
- [x] 在原始返回层保留 structuredContent、多内容块及完整附加事实；data 优先结构化内容，没有则为内容块数组，details 保留原返回和来源。isError、协议/SDK 来源输出校验异常为失败，不经有损转换后假装完整成功。
- [ ] MCP 调用使用同一严格输入校验、总预算、结果限额、错误分类与已知凭据遮盖；测试使用本地可控 stdio 服务，无需公网和模型，结束清理本次持有的连接/进程。
- [x] 通过公开 API 验证连接暂不可达可保存、发现不执行业务、勾选批次、同来源 ID 和真实返回；页面验收 MCP 服务与工具页跳转、动态参数和完整结果，并完成相关后端、前端测试与构建。

## Comments

2026-10-14 用户要求记录并在 MCP 开发时落实[普通编辑与发现更新的接入规则](../tool-edit-drafts.md#mcp-普通编辑与发现更新的接入规则)。`save_tool` 与 `start_draft_test` 显式执行 `_check_tool_edit_permissions`；`_prepare_tool` 已不包含 MCP 普通编辑的只读限制。发现勾选入库须由独立后端入口核对真实来源、用户选择和版本，复用定义准备及配置提交，整批校验后一次提交，不能逐项调用 `save_tool`。同来源重复入库保留 ID；后续 schema 更新见 09，不应被普通编辑限制拦截。普通接口不能接受客户端标志来绕过权限，07／09 需通过公开接口验证两种操作的权限差异。

2026-10-18 已提交 stdio 主链路实现，连接敏感字段协议及已知凭据遮盖仍未完成。沿用 2026-10-15 用户移除 credential、后续统一设计的决定，不直接恢复旧抽象。已向用户询问范围选择，未将无回复视为凭据方案确认。实现、验证和 09 接入注意事项见 [MCP stdio 接入记录](../mcp-stdio-tools.md)。
