# 01: 创建并测试第一个 HTTP 工具

> 历史开发票：2026-10-23 从本机 scratch 迁入，保留原状态、验收项和阶段记录。当前实现与后续修订先读[开发指南](../README.md)和[实施索引](index.md)。

**页面原型：** 涉及工具页的开发与验收，先读取并遵循[工具页面原型与参照规则](../../../../frontend/design.md#工具页面原型)。

**What to build:** 用户从“扩展 → 工具”创建一个无参数、无认证的 GET 工具，保存后重新打开，并真实调用一个 HTTP 接口、查看完整结果。将必要的配置来源传递和页面导航调整放在本票最先实施，随后贯通第一条可演示链路；采用公共定义与 HTTP 专属子类、登记适配器及统一执行入口，后续票据逐步扩展能力。

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] 主导航可以进入扩展下的工具页面；MCP 服务和技能有明确预留位置，技能显示暂未开放。工具页使用完整编辑布局，聊天历史仍只出现在聊天工作区；既有聊天与宿主交互可继续使用。
- [x] 复用项目已接入的 shadcn 基础控件、主题语义、AI Elements 本地源码路线及固定为 6.11.0 的 rjsf 依赖，按需追加工具业务 Form/Tool 适配并完成构建；不重复初始化组件库。配置按管理 schema 动态渲染，测试输入来自业务 input_schema，既有 Reasoning 和后端通信契约保持有效。
- [x] 实际 Form 启用 shadcn 主题的 Tailwind 样式扫描并沿用现有主题语义，所需 widgets/templates 与本地控件一致，不导入第二套完整全局 reset；既有组件已接入不等于业务表单已挂载，必须在真实页面验证。
- [x] 可创建、列出、读取和保存 HTTP 工具；公共信息包含稳定 ID、类型、页面名称、调用名称、说明、输入/可选输出 schema、启用、系统时间和独立超时。新工具默认启用，超时默认 30 秒并校验 1–300 秒。
- [x] 页面名称可以中文和重复；调用名称自动生成合法唯一候选并避开内置工具名，手动冲突由后端明确拒绝。无参数使用对象 schema，测试输入为空参数对象，不用页面名称充当工具身份。
- [x] 工具定义与执行逻辑分层，HTTP 专属字段不混入通用 config 字典；按类型登记适配器。新增定义保存到项目实际加载的工具库分组，保持独立 MCP 连接位置及既有启动 MCP 配置的分离，不自动装配到当前聊天 Agent。
- [x] 后端取得实际配置来源，更新原始配置的工具库内容并替换提交；其余分组、环境引用和相对路径保留，工具库字符串按字面处理。保存后刷新或重新加载仍能读取同一工具 ID，不以内存列表作为持久存储。
- [x] 可以通过公开 API 发起、观察一次已保存工具测试，并通过按 ID 的执行入口取得结果，无需 LLM 或完整 Agent Run；页面显示真实加载、空列表、保存失败与测试状态，读取失败不把旧视图当成已核实执行配置。
- [x] 统一结果包含 status、data、error、duration_ms、details，真实 JSON/文本/空结果保持类型；2xx 成功，其他状态失败并保留可用响应，HTTP 工具不跟随重定向。二进制明确未支持，实际返回超过 1 MiB 明确失败，不显示截断成功内容。
- [x] Tool 呈现按真实测试/结果状态适配，明确展示 null、false、0、空字符串和空容器，不沿用上游真假值过滤；显示与复制的格式化不改变结构化 data，不为展示引入另一套消息/执行 store 或 AI SDK transport。
- [x] 对当前 GET 链路实施输入与配置校验及包含请求/结果读取的执行预算，异常不能作为成功正文返回；为后续类型和可取消测试保留同一执行契约，具体取消交互由 12 完成。
- [x] 用临时配置和本地 HTTP 服务通过公开 API 验证创建、重读、名称冲突、保存保留原配置、真实响应及错误行为；复用已有 Testing Library/jsdom 挂载真实业务 Form/Tool，检查实际提交及 null、false、0、空字符串结果可见。Tauri 实际页面验收导航、动态配置表单、主题及完整结果查看，并完成相关后端检查、前端测试与构建。
