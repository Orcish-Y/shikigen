# 12: 测试取消、超时与运行中交互

> 历史开发票：2026-10-23 从本机 scratch 迁入，保留原状态、验收项和阶段记录。当前实现与后续修订先读[开发指南](../README.md)和[实施索引](index.md)。

**页面原型：** 涉及工具页的开发与验收，先读取并遵循[工具页面原型与参照规则](../../../../frontend/design.md#工具页面原型)。

**What to build:** 用户发起三类工具测试后可以观察状态和取消，测试期间不能把编辑内容改成另一个版本；离开先决定是否取消测试，再处理未保存草稿。执行超时和资源清理有可观察结果，四种状态保持明确。

**Blocked by:** 03：工具编辑、启用、删除与草稿测试；05：创建并测试带注解的 Python 工具；07：接入 stdio MCP 并调用选中工具。

**Status:** done

- [x] 公开 API 支持开始、查询、取消已保存或有效草稿测试，临时测试身份用于观察和取消，无需完整 Agent Run、LLM 或持久测试历史；草稿测试不自动保存，禁用显式测试与普通调用资格保持分开。
- [x] 同一编辑页一次测试，运行期间锁定编辑和保存，显示真实进行状态并提供取消；重复开始有明确反馈，测试结果对应启动时的有效定义和输入。
- [x] 切换页面或关闭编辑先提供取消测试并离开/继续测试，取消处理后仍检查未保存草稿，再提供保存、放弃、继续，不因确认取消而静默丢失修改。
- [x] 完成或取消后恢复编辑，展示 success/error/timeout/cancelled、data、脱敏 error、duration_ms 和完整 details；修改相关配置标记旧结果，无记录不自动探测在线。
- [x] AI Elements Tool 展示从本项目真实状态适配，超时与取消独立可见，不改成拒绝审批或笼统成功；null、false、0、空字符串等结果明确展示，未取得响应与真实 null 可区分，完整数据和类型仍可查看复制。
- [x] 工具总预算包含启动/连接、业务与结果读取，默认 30 秒、范围 1–300；MCP 测试连接和发现按独立连接预算。清理可能增加 duration_ms，不能把各传输阶段独立超时当成完整预算。
- [x] 取消或超时终止并回收本次 Python 子进程，取消 HTTP/MCP 等待并释放本次持有会话/连接和临时资源；后端生命周期结束不遗留自身持有测试资源。不承诺所有派生进程停止或远端业务撤销，不自动重试业务操作。
- [x] 已有各类型限额继续有效：实际返回超过 1 MiB 明确失败，Python 调试输出按 64 KiB 截断标记，超时/取消不伪造成功数据；所有可显示和可复制内容遮盖已知凭据。
- [x] 前端沿用宿主身份与取消请求机制，失效宿主的迟到响应不能覆盖当前测试状态；明确的取消意图与请求断开区分处理，不仅关闭浏览器等待而留下未处理测试。
- [x] 以真实 Python 子进程、本地 HTTP 和可控 MCP 服务经公开 API 验证阻塞、超时、取消、查询与清理，采用同步信号避免固定 sleep 偶然成功；此时已接入的远程传输同样遵循契约，08 后续接入也继承共同边界。
- [x] 页面验收锁定、取消、离开两阶段选择、完成恢复和四种结果展示，复用现有 Testing Library/jsdom 操作真实工具结果组件，检查迟到响应及 null、false、0、空字符串输出可见；完成相关后端、前端测试与构建。

## 实现记录

已完成，见 [测试生命周期实现](../test-cancellation-lifecycle.md) 与 [审查验证记录](../test-cancellation-lifecycle.review.md)。公开 API 与真实 Python/HTTP/MCP 验证取消、预算和清理；开始请求同时由后端生成临时身份并启动执行，202 返回测试 ID；不再使用独立登记、reserved 状态或登记过期。开始响应丢失时明确提示无 ID、不可查询／取消，不自动重试，用户可停止等待，后端按执行预算清理。取消只接收 ID，不依赖前端 pending 或额外的待交接集合；不增加完整 Agent Run 或持久测试历史。配置中的认证值仍按用户决定直接编辑保存，执行观察统一脱敏。
