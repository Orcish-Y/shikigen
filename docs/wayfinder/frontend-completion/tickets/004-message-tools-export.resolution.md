## 结论

采用已确认的[消息、工具、导出与本地资源契约](004-message-tools-export.contract.md)作为首版实施依据。完整字段、保存边界、竞态、工具呈现、本地资源、确认打开与导出格式统一记录在该资产中。

**做什么：**补齐真实消息与工具记录的呈现、取消／失败时保存生成正文、工作目录内图片自动预览、文件确认打开，以及范围明确的 Markdown 导出。

**为什么：**当前模板尚未呈现全部公开消息字段；未提交正文仅存在后端内存；本地资源和系统打开缺少契约。保留真实事实和独立中止标记，才能在重开会话及导出时核对已经产生的内容。

**用什么 API：**沿用历史、Run messages 和 SSE；消息结算新增 generation_status 与原子中止保存；新增只读 workspace/resources 查询与图片响应；Tauri 新增受控网页打开、文件准备及确认打开命令。Markdown 导出使用本地已提交快照，不新增导出 HTTP。上述新增能力均待实施。
