- **做什么：**锁定原稿的视觉系统、两态一致性和 Tauri 内容区尺寸换算，记录当前应用需要对齐的差异，并明确实机验收责任。

## 视觉基准

- 展开原稿统一菜单和基础视觉；折叠原稿提供收起比例，两态继续使用同一套样式和操作语义。
- 新页面与组件尽量贴近原稿，沿用既有白色画布、Slate、Indigo、字体、描边图标、细边框与紧凑布局。
- 布局以 WebView 内容区 CSS px 表达，区分原生标题栏、显示缩放和 PNG 像素。约 1.5 倍缩放与近似视口的判断继续标为推断。
- 当前导航头、消息／工具排版与输入密度按设计规范对齐；原稿示例控件和数据按已确认功能范围适配。

尺寸、色值、字号及新增组件细则由设计规范维护，此处不另建一套规格。
