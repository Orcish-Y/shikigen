# 每次确认后用系统程序打开工作目录文件

Status: ready-for-agent

实施进度：待实施

来源：[统一实施规格](../../../../.scratch/frontend-completion/PRD.md)；[公共要求与依赖总览](index.md)。

**What to build:** 点击 Agent 本地文件链接先核实真实目标，每次确认后用系统默认程序打开，目标变化时重新确认。

**Why:** 为本地文件建立明确的一次性打开意图，复用已核实工作目录与资源服务。

**API／边界：**prepare_workspace_file_open、open_prepared_workspace_file；宿主自管后端租约／资源解析；opener 受控命令、统一确认模态。

**Blocked by:** [自动预览工作目录内的本地图片](14-workspace-image-preview.md)。

## 验收条件

- [ ] prepare 接收 startupId／原引用 path，宿主使用自管地址和根核实，返回一次性 request_id、启动／目录身份及完整真实文件元数据，不接受调用者地址或根，不在准备阶段打开。
- [ ] 意图绑定 main 窗口和租约、五分钟过期；open 仅 request_id，再验目录、路径和文件版本，使用后／关闭／失效不复用，不开放任意路径通用权限或拼 shell。
- [ ] 每次点击包括图片用系统打开都重新准备；确认显示文件名、完整路径、默认程序说明与复制，取消／确认打开，默认取消，Esc／遮罩／关闭零打开。
- [ ] 切会话、引用变化、隐藏和租约失效关闭；路径或版本变化重新准备并新确认，不静默换目标，pending 防重复，失败显示真实原因。
- [ ] 成功只表示系统接受，不自动再打开，不改变 Run／SSE／审批；直接浏览器示例说明桌面能力，未知协议与目录打开保持只读说明。
- [ ] 公开命令与实际默认程序验证越界、变更、过期、重复、无默认程序和取消；焦点返回有效入口且只有单前景模态。
