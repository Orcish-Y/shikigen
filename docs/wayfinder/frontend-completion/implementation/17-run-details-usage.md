# 查看当前运行详情与真实累计用量

Status: ready-for-agent

实施进度：待实施

来源：[统一实施规格](../../../../.scratch/frontend-completion/PRD.md)；[公共要求与依赖总览](index.md)。

**What to build:** 进入会话就读取本次运行用量，打开详情查看真实身份、状态、时间、错误和模型累计值，刷新失败不清已有内容。

**Why:** 用同一事实解释任务与统计，区分执行结果、读取状态和结算状态。

**API／边界：**纯读 RunSnapshot、SSE metadata、有效 cancel 快照；共享字段／执行阶段版本和请求协调；现有详情抽屉／底部面板。

**Blocked by:** [隐藏暂停读取并轮询会话状态](06-visibility-polling.md)；[安全 Markdown、网页链接与完整内容查看](07-markdown-content-viewer.md)。

## 验收条件

- [ ] 历史定位后自动一次快照，打开详情刷新；同目标同类不重叠，进入时在读复用，读失败不阻塞适用 SSE，已有值刷新不闪空。
- [ ] 详情跟当前／最近 Run，无历史切换器；共用工具栏／摘要入口，无 Run 与身份未知分开；切会话关闭，新 Run 接受后换目标清旧 UI 选择和失效请求。
- [ ] 展示实际会话／Run ID、中文状态、错误／code、服务端创建／更新／结束时间，完整复制、本地时区与 UTC 可核对；未知结束时间不补接收时间。
- [ ] 用量显示 total_input／output／tokens、已记录模型完成回调 calls 和真实 by_model，未知不是零，缺项不补模型、不重算总量，不表示工具次数／账单／速度／上下文比例。
- [ ] 用量 pending 与终态分开；同 Run 新阶段保留累计但旧 false 待重新确认，metadata 省略保留、usage=null 未知，旧 null／阶段快照不清新字段，updated_at 相同可补晚量。
- [ ] 会话栏本次运行用量紧凑真实值和详情入口，长值可换行，新目标不闪旧值；分运行信息／用量，读取／观察／执行错误分别显示。
- [ ] 开关详情不建第二 SSE、不停止观察或取消；完整错误、ID、模型只读查看复用单前景；公开快照／时序和实机验未知／零／多模型／取消晚量／旧响应。
