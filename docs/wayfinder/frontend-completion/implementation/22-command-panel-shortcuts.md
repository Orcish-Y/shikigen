来源：[统一实施规格](../../../../.scratch/frontend-completion/PRD.md)；[公共要求与依赖总览](index.md)。

**What to build:** 搜索操作与已加载会话并用键盘执行；输入时也能 Cmd/Ctrl+K／N／B，但输入法、长按和其他前景面板不会误触后台操作。

**Why:** 共享已经完成的命名、导航和详情行为，提供一致快速入口并保护前景意图。

**API／边界：**共享新建／会话切换／导航／详情动作，本地显示标题和已加载列表；键盘组合、IME／repeat、单前景与焦点返回。

## 验收条件

- [x] 约480px原生dialog，搜索操作／已加载会话，仅本地动作名与显示标题，无服务端搜索／批读历史；搜索与侧栏过滤独立，长列表区内滚动。
- [x] 方向键选可用项、Enter执行、Esc关闭，初始搜索焦点，IME候选不执行、repeat不重复；禁用项说明实际原因，无匹配不默认新建。
- [x] 新建、切换、导航和详情与页面动作共享资格／pending，执行后正确关闭或替换前景，不清草稿、不加第二SSE，不取消其他Run。
- [x] 平台Cmd／Ctrl+K／N／B在普通草稿／搜索输入可用，只处理普通组合；模态阻止全局动作，仅K关自身命令、B关自身导航覆盖，不替换其他详情／确认。
- [x] Esc只关当前层不继续传播关闭／取消／提交，Tab约束及可见焦点、失效入口回稳定工作区；窄屏B不写桌面偏好，按钮入口仍可用。
- [x] 公开动作与实机验证输入／过滤、无匹配、创建pending、切换迟到、K／B关自身、中文IME、长按、详情替换和各档焦点返回。
