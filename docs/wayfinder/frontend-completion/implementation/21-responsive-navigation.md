# 原稿风格的响应式导航与桌面偏好

Status: ready-for-agent

实施进度：待实施

来源：[统一实施规格](../../../../.scratch/frontend-completion/PRD.md)；[公共要求与依赖总览](index.md)。

**What to build:** 以原稿比例在桌面两态、平板互斥侧栏和手机单菜单中浏览会话，布局变化保留文字和阅读位置，主动桌面偏好跨重启恢复。

**Why:** 为全部首版组件提供统一窗口布局和前景行为，保持既有视觉与不同尺寸操作可达。

**API／边界：**CSS 内容区断点、共享导航／列表动作、桌面 localStorage 偏好、单前景 dialog、现有状态／输入和阅读锚点。

**Blocked by:** [自动分页浏览带状态的会话列表](02-paginated-conversation-list.md)；[原文发送并保留持久消息草稿](04-message-drafts-send.md)；[安全 Markdown、网页链接与完整内容查看](07-markdown-content-viewer.md)；[恢复聊天阅读位置与自动跟随](09-chat-reading-position.md)。

## 验收条件

- [ ] 遵守白／Slate／Indigo、Geist／JetBrains Mono、Phosphor regular、细边框／小圆角，展开原稿主视觉与菜单、折叠 64px 比例；修主按钮 hover 等已确认缺陷，新增组件仍沿用同控件语法。
- [ ] ≥1440 无主动偏好 256＋256，1280–1439 默认 64＋256 可展开，768–1279 固定 64＋256 互斥覆盖，<768 单菜单每次默认会话列表、同面板切主导航。
- [ ] 两态同菜单／选中／禁用原因；仅桌面主动选择写偏好，默认／resize／窄屏不写，回桌面恢复；主导航中段滚动而头尾可达，列表独立。
- [ ] 40px 网页栏在原生标题栏下，840px 消息／输入中轴，角色约 15／22、正文约 14／24、24px 消息距、28px 头像与12px间隔，用户浅灰／Agent 白画布。
- [ ] 输入两行约48px、最高约180px内滚，长代码／JSON约320px，桌面400px抽屉／窄屏约80dvh，关键14px／44px触控目标；内容和提示真实占布局不遮必要操作。
- [ ] 菜单换视图保留过滤／页／位置／草稿，跨断点关闭覆盖并返有效焦点，单前景无双 dialog；布局不 GET 历史、不重建 SSE、不 cancel，已有控件使用同一可达性规则。
- [ ] 真实 Tauri 四档 CSS 内容区记录大小／DPI，对比原稿和既有桌面截图；演示已接入的浏览、输入、完整查看及长内容／提示，最终全流程在联合验收再次覆盖。
