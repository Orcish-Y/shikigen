# 恢复聊天阅读位置与自动跟随

Status: done

实施进度：已验收

来源：[统一实施规格](../../../../.scratch/frontend-completion/PRD.md)；[公共要求与依赖总览](index.md)。

**What to build:** 首次打开看最新，切回继续原阅读位置，上翻后新输出不抢位置，并可主动回到最新或定位审批。

**Why:** 保护用户在长会话中的阅读意图，给后续图片和布局变化提供稳定锚点。

**API／边界：**完整消息／卡片稳定身份、应用内按会话阅读记录、主时间线滚动和布局变化。

**Blocked by:** [全量重建消息与当前运行事实](03-run-fact-reconstruction.md)。

- [x] 锚点未出现等待事实恢复，失效时用最近存在内容，不盲复用其他会话 scrollTop。
- [x] 主动上翻立即停跟随，delta、完整替换、工具区变化和图片／宽度变化不抢位置；内部代码滚动不当作主时间线上翻。
- [x] 回到最新或主动滚回底部恢复；有新内容提示不按 delta 数造消息数，主动发送有效接受可跟随，后台查询／状态／用量不强制到底。
- [x] 主动处理审批才定位卡片并转有效焦点，导航、列表、时间线与详情各自滚动。
- [x] 验证切换、宿主重入、重复事实、动态高度和失效目标，在实机保留正在阅读消息并能返回最新；软键盘／输入增高的联合检查留给最终验收。
