## 验收条件

- [ ] 逐项覆盖原PRD首版1–17及116用户故事对应行为，各项记录预期／实际、必要thread_id／run_id／startup_id和证据；待执行保留待验收，失败明确归属修正。
- [ ] 真实模型正常任务、write_file／bash等工具审批／拒绝、同Run继续、running／interrupted取消、自然完成竞争、断流／重连、刷新／重开、后台隐藏与显示均可完成。
- [ ] 跨分支覆盖迟到／重复／乱序、旧租约、未知写结果、持久草稿、审批换请求、封存回滚／晚Graph快照、终态消息补读、事件和用量晚结算，不伪造状态或记录。
- [ ] 本地图片及文件系统打开／确认取消、资源越界／变更／过期、Markdown完整复制与点击时导出可核对；系统打开和下载有真实结果，夹具范围与真实路径分别注明。
- [ ] 1440×900、1280×800、1024×768、390×844为实际CSS内容区，记录Windows缩放／截图像素／原生标题栏；展开／收起、平板覆盖、手机默认列表、桌面偏好贴原稿。
- [ ] 长代码／JSON／参数／artifact／路径、图片加载、输入增高、软键盘／托盘提示并存时，阅读锚点、发送／审批／取消／重连和完整查看可达；IME、触控、单前景／Esc／焦点真实操作核对。
- [ ] 现有后端托管、单实例、托盘、动态地址基线有效；由应用托管实际后端，不用争用数据目录的另一实例代替整条路径。
- [ ] 全部票据各自的验证结果与联合证据可复查；实现缺陷归入修正，涉及产品规则变化另开决策，不修改或重开已关闭的父地图。
