# 查看已提交运行事件与审批历史

Status: done

实施进度：已完成

来源：[统一实施规格](../../../../.scratch/frontend-completion/PRD.md)；[公共要求与依赖总览](index.md)。

**What to build:** 在详情按真实序号阅读生命周期和审批事件，可包含消息事件并完整查看复制，刷新或补读只显示已发生事实。

**Why:** 为运行结果提供可核对的历史，复用公开 SSE 投影而不依赖本地动作猜测。

**API／边界：**新增纯读 Run events JSON、既有 SSE event；seq 合并、详情读取协调和共用完整查看。

**Blocked by:** [查看当前运行详情与真实累计用量](17-run-details-usage.md)。

## 验收条件

- [x] 新增 events 返回查询时全部已提交公开 RunEvent、seq ASC，结构与 SSE 相同，首版无分页／服务端过滤；归属校验、no-store 和纯读错误不执行恢复或写 Run。
- [x] 打开详情独立并行快照／事件、各自无重叠和分区错误；已有事实刷新保留，一次查询缺项不删除，seq 空洞不报丢失，同 seq 冲突只读协议问题。
- [x] 默认 lifecycle／approval，开关含 message 只过滤；类别、真实时间、seq、required／resolved／invalidated／message 标记可读，空记录和过滤后空分开。
- [x] 历史决策与原因只用后端实际载荷，本地选择／HTTP 200／当前终态不造事件；未校验记录不接入事实，JSON 中路径／网页／图片保持原文。
- [x] 展开完整 JSON、复制完整事件和原字段，约 320px 内滚动，完整查看为同前景只读子视图，返回保留位置／焦点，不新增审批或取消表单。
- [x] 详情打开的正常 interrupted／终态 EOF 或 cancel 终态一次补读，确认前正在读最多合并一次确认后读取，重复通知不排队；关闭停专属事件读和重试，SSE／事实保留。
- [x] 公开 HTTP／SSE 验重复、乱序、取消后事件补齐、两查询不同刻／一失败，以及未取得事实不伪造；实机历史可完整查看复制。
