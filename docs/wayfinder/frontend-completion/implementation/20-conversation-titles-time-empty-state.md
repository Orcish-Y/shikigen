# 会话标题、日期时间与空态引导

Status: ready-for-agent

实施进度：待实施

来源：[统一实施规格](../../../../.scratch/frontend-completion/PRD.md)；[公共要求与依赖总览](index.md)。

**What to build:** 用易识别标题与本地时间浏览会话，真实空态提供任务示例，已有草稿点击示例只追加。

**Why:** 让列表、工具栏和后续命令共享可理解名称，同时保留输入和真实范围。

**API／边界：**已有会话字段和首条已提交用户文本、本地标题缓存、分钟显示计时、本地日期／时区、共享新建与草稿动作。

**Blocked by:** [自动分页浏览带状态的会话列表](02-paginated-conversation-list.md)；[原文发送并保留持久消息草稿](04-message-drafts-send.md)。

## 验收条件

- [ ] 服务端非空 title 优先，首条已提交用户明确文本派生临时一行标题并按会话跨重启缓存，打开历史核对，未读为新会话；不取草稿／未知块、不批读所有历史、不 PATCH。
- [ ] 列表／工具栏／本地过滤使用同显示标题，完整标题键盘／触控可查，服务端 null 不无故清已核实缓存，缓存失败保留内存提示。
- [ ] 真实 updated_at 排序，本地今天／昨天／更早按日历；刚刚／分钟／小时／天，七天起日期，完整本地时区及 UTC 可复制。
- [ ] 可见每分钟刷新文案，显示／跨日立即重算不增 HTTP；未来时间绝对显示，未知时间说明，未来日历／未知日期列日期待确认，不补时间。
- [ ] 未加载／失败不是空态，真实无会话提供新建；空会话三例仅空草稿填入／已有空行分隔追加，聚焦不自动发，迟到读取不抢其他输入或模态。
- [ ] 公开历史与本地状态验证缓存核对、正式标题覆盖、跨日／七天／时区／未来与无效时间、示例原文和异步焦点，实机列表可核对且草稿不丢。
